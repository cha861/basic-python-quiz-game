## 🧠 Computer Quiz Game (Python)

A simple command-line quiz game built using Python.
This project is meant for beginners to practice basic Python concepts like input/output, conditions, and variables.

## 📌 Features

Interactive quiz in the terminal

Asks basic computer-related questions

Keeps track of the user’s score

Displays final score and percentage

## 🛠️ Technologies Used

Python 3

▶️ How to Run the Program

Make sure Python 3 is installed on your system.

Clone the repository or download the file.

Open a terminal in the project folder.

Run the program using:

python quiz.py


(Rename the file name if needed.)

### 🎮 How It Works

The program asks if you want to play.

If you type yes, the quiz starts.

Answer the questions related to computer basics.

Your score and percentage are shown at the end.

String methods like .lower()

Variables and basic arithmetic
